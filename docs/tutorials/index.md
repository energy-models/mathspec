# Tutorials

In each tutorial you build one specification of an optimisation model
(a [spec](../reference/glossary.md#spec)), step by step, and check it after every
step. Do the tutorials in this order:

<div class="grid cards" markdown>

<!-- prettier-ignore -->
- In **[Your first spec](first-spec.md)** you build a least-cost dispatch spec
    one section at a time, check it, and print it as math.
- In **[A storage unit over time](storage.md)** you order the hours, link
    each hour to the one before, and leave out batteries with no capacity.
- In **[A spec in several files](several-files.md)** you merge a spec from
    several files, then add a component without changing the others.

</div>
